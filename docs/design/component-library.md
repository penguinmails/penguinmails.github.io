# Component Library

**Comprehensive catalog of all reusable UI components available in PenguinMails.**

---

## Component Categories

Explore our modular component library organized by function and usage patterns:

### 1. [Primitives](/docs/design/component-library/primitives)

Foundational building blocks including `Button` and `Input` components with technical specs.

### 2. [Layout Components](/docs/design/component-library/layout)

Structural components for building page shells and grids, including `Container` and `Grid`.

### 3. [Form Components](/docs/design/component-library/forms)

User input and selection controls including `FormField`, `Select`, `Checkbox`, and `Radio`.

### 4. [Data Display](/docs/design/component-library/data-display)

Information visualization and structural display components like `Table` and `Card`.

### 5. [Feedback & Overlays](/docs/design/component-library/feedback-and-overlays)

Interactive messaging and overlay systems including `Alert`, `Toast`, and `Modal`.

### 6. [Navigation & Utilities](/docs/design/component-library/navigation-and-utilities)

Wayfinding and helper components like `Breadcrumb`, `Tabs`, `Loading`, and `Badge`.
