# Template Variables

Template variables allow you to personalize your email content dynamically using merge tags, conditional logic, and custom filters.

## Documentation Sections

This guide is organized into the following sections:

### 1. [Basic Merge Tags](/docs/features/templates/template-variables/basic-merge-tags)

Standard contact fields, workspace variables, and simple default values.

### 2. [Conditional Logic](/docs/features/templates/template-variables/conditional-logic)

If/else blocks, complex Boolean logic, and personalized content delivery based on user attributes.

### 3. [Advanced Formatting](/docs/features/templates/template-variables/advanced-formatting)

Dynamic links, image personalization, date formatting, and loops for iterating over lists.

### 4. [Technical Implementation](/docs/features/templates/template-variables/technical-implementation)

Database schema for custom variables and details on the template variable parser.

### 5. [API Reference](/docs/features/templates/template-variables/api-reference)

API endpoints for parsing templates and managing custom variables.
