# Compliance & Certifications

PenguinMails is built to meet the rigorous requirements of global data protection laws and industry security standards.

## 1. Data Privacy Frameworks

- **GDPR (General Data Protection Regulation)**: We provide tools for data portability, the "Right to be Forgotten," and encrypted data storage.
- **CCPA (California Consumer Privacy Act)**: Management of consumer data rights and privacy disclosures.
- **CAN-SPAM & CASL**: Native tools for one-click unsubscribes and mandatory physical address inclusion in email footers.

## 2. Security Certifications

- **SOC 2 Type II**: *In Progress (Q2 2026).* Auditing our controls for security, availability, and confidentiality.
- **ISO/IEC 27001**: *On Roadmap (Q3 2026).* International standard for information security management systems.
- **HIPAA Compliance**: *Available for Enterprise.* Specialized BAA (Business Associate Agreement) for healthcare organizations.

## 3. Regular Audits

- **Penetration Testing**: Conducted quarterly by independent third-party firms.
- **Vulnerability Scanning**: Automated scans run weekly on our entire infrastructure.
- **Internal Reviews**: Monthly security council meetings to review logs and update policies.

## 4. Responsibility Matrix

| Feature | PenguinMails Responsibility | Customer Responsibility |
|---------|-----------------------------|-------------------------|
| **Domain Authentication** | API/Tools for records | Correct DNS configuration |
| **Data Encryption** | AES-256 for all stored data | Secure handling of API keys |
| **Tenant Access** | Multi-tenant isolation | Strong user passwords & 2FA |
| **Email Content** | Spam filtering algorithms | Compliance with CAN-SPAM laws |
