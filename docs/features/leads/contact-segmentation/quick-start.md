# Segmentation Quick Start

Contact Segmentation enables you to divide your contact database into meaningful groups based on shared characteristics, behaviors, or custom criteria.

## Your First Segment

### Step 1: Create Segment

Navigate to **Contacts → Segments → Create New Segment**. Give it a name like "Active Subscribers" and choose between **Dynamic** or **Static**.

### Step 2: Define Rules (Dynamic Segment)

Set conditions that contacts must meet to be included. For example:

- **Last Email Opened**: within last 30 days
- **Subscription Status**: Active
- **Unsubscribed**: No

### Step 3: Save & Use

Once saved, you can immediately use the segment in campaigns or export the list for external use.

## Common Segment Types

### By Engagement Level

- **Highly Engaged**: Multiple opens and clicks within the last 30 days.
- **Inactive Contacts**: No opens in the last 90+ days.
- **Never Engaged**: Zero total activity.

### By Demographics

- **Location-Based**: Filtering by country, state, or city.
- **Company Attributes**: Using custom fields like `company_size` or `industry`.

### By Lifecycle Stage

- **New Leads**: Contacts added within the last 7 days.
- **Trial Users**: Current trialists with expiring dates.
- **Customers**: Those with recent purchase history.

## Static Segments

Static segments are manual, fixed lists that do not auto-update. Use them for:

- One-time event invitations.
- Manual contact selection.
- Imported CSV lists.
- A/B test control groups.
