# Manual Reporting & Data Export

**Flexible report generation and data extraction for external analysis and stakeholder reporting.**

Manual Reporting complements the live dashboards with automated scheduling and deep-dive export capabilities.

---

## Implementation Modules

Explore the following modules for detailed guides and technical specs:

### 1. [Scheduled Reporting](/docs/features/analytics/manual-reporting/scheduled-reports)

Automated intelligence via recurring daily, weekly, or monthly performance summaries.

### 2. [External Tools & Export](/docs/features/analytics/manual-reporting/external-integrations)

Connecting with Google Sheets, Excel, and BI platforms via CSV, JSON, and XLSX exports.

### 3. [Technical Implementation](/docs/features/analytics/manual-reporting/reporting-technical)

Detailed database schemas, generation service logic, and S3 storage management for developers.

---

## Quick Start

1. **Dashboard** → **Analytics** → **Reports**.
2. Click **"Create New Report"**.
3. Choose your **Report Type** (e.g., Campaign Performance).
4. Set your **Frequency** and **Recipients**.
5. Click **"Schedule"**.
