## Feature Roadmap: Inbox Management

### MVP Roadmap (Q4 2025 - Q1 2026)

* **[P0] Stalwart Mail Server Database Spike** (Q4 2025)
  * Determine integration approach with Stalwart's PostgreSQL schema
  * **Critical blocker:** Foundation for all inbox development.
* **[P0] Email Threading Algorithm** (Q1 2026)
  * RFC 5322 header matching (References, In-Reply-To)
  * **Business Impact:** conversation-based inbox management.
* **[P0] Star/Favorite & View System** (Q1 2026)
  * Star/unstar threads, folder management (Sent, Archived, Trash)
  * **Business Impact:** Core inbox UX.

### Post-MVP Roadmap (Q2-Q3 2026)

* **[P1] Smart Reply Suggestions (Gemini AI)** (Q2 2026)
  * AI-generated reply options based on thread context
  * **Business Impact:** Improves sales rep efficiency.
* **[P1] Sentiment Analysis & Tone Detection** (Q2 2026)
  * Detect emotional context of replies
  * **Business Impact:** Tailored responses based on prospect mood.
* **[P1] Advanced Inbox Analytics** (Q2 2026)
  * Response time, conversion rate, rep performance metrics
  * **Business Impact:** Data-driven optimization and team visibility.
* **[P2] Scheduled Sending & Multi-Language** (Q2-Q3 2026)
  * Schedule replies and AI-powered translation for global outreach.
